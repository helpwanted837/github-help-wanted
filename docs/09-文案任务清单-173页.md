## 质量检查清单

每篇文章提交前，确保通过以下检查：

### 必检项

- [ ] 字数达标（Pillar ≥3000 / Cluster ≥2000 / Extension ≥1500）
- [ ] References 区块有 5+ 条权威引用
- [ ] 引用来源 URL 可访问
- [ ] FAQ 区块完整（Pillar 5-8 / Cluster 5 / Extension 3-5）
- [ ] Key Takeaways 区块存在
- [ ] 至少有 1 个对比/功能表格（Pillar/Cluster）
- [ ] 至少有引用块（> "quote"）
- [ ] Front Matter 完整（title, description, date, draft, type, keywords, faq）
- [ ] `draft: true` 已设置
- [ ] 无拼写/语法错误

### 审计命令

完成后可运行审计脚本验证：

```bash
python scripts/audit_content_quality.py --limit 20
```

## 提交流程

1. **撰写**: 按模板完成内容
2. **自检**: 对照质量检查清单
3. **提交**: 将 `.md` 文件放入正确目录
4. **审核**: 等待架构师审核
5. **发布**: 审核通过后，修改 `draft: false` 并设置 `date`
