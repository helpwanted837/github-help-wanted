# 01 - 域名分析

> github-help-wanted.com 外链分析与 URL 承接规划

---

## 1. 域名历史

- **原站功能**: GitHub Issue 聚合器，帮助开发者找 "help wanted" / "good first issue"
- **原站技术**: 调用 GitHub API，按语言和标签筛选 Issue
- **目标用户**: 想参与开源贡献的开发者（日本开发者社区尤其活跃）

## 4. 必须承接的 URL 路径

### 首页（核心，167+ 外链指向）

```
https://github-help-wanted.com/
http://github-help-wanted.com/
```

**承接策略**: 首页必须保留，可以是工具页或内容聚合页

### 带参数的筛选页

```
/?languages=&labels=hacktoberfest&page=1&sort=created&order=desc
/?languages=Python&labels=help+wanted&page=1&sort=created&order=desc
```

**承接策略**:
- 方案 A: 重建类似的筛选功能（技术成本高）
- 方案 B: 301 重定向到相关内容页（推荐）
- 方案 C: 创建对应的静态页面 `/hacktoberfest/`、`/python-help-wanted/`

## 5. 外链语义聚类

基于外链来源的上下文，提取主题聚类：

| 主题 | 权重 | 代表来源 |
|------|------|----------|
| OSS/开源贡献入门 | 高 | Qiita 系列、envader |
| GitHub Issue 发现 | 高 | HN、Scrapbox |
| Side Project 灵感 | 中 | HN 讨论 |
| 开发者工具推荐 | 中 | 各类技术博客 |
| Hacktoberfest | 低 | Scrapbox 单条 |

---

## 6. 语言分布

| 语言 | 占比 | 说明 |
|------|------|------|
| 日语 (JA) | ~60% | Qiita 系列是主力 |
| 英语 (EN) | ~40% | HN、国际技术博客 |

**启示**:
- 日语开发者社区对这个域名有认知
- 可考虑日语内容（但会增加复杂度）
- 英语优先，但要意识到日语用户可能会访问
