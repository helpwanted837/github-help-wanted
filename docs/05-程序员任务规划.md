## Phase 5: 部署上线

### 5.1 GitHub Actions 配置

**参考手册第 5 节**

```yaml
# .github/workflows/scheduled-deploy.yml
name: Scheduled Deploy

on:
  push:
    branches: [main]
  workflow_dispatch:
  schedule:
    - cron: '0 * * * *'  # 每小时检查

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Check if deploy needed
        if: github.event_name == 'schedule'
        id: check
        run: |
          pip install pyyaml
          result=$(python scripts/decide_deploy.py)
          echo "should_deploy=$result" >> $GITHUB_OUTPUT

      - name: Random delay
        if: github.event_name == 'schedule' && steps.check.outputs.should_deploy == 'true'
        run: sleep $((RANDOM % 900))

      - name: Setup Hugo
        uses: peaceiris/actions-hugo@v2
        with:
          hugo-version: 'latest'
          extended: true

      - name: Generate internal links
        run: |
          pip install -r scripts/requirements.txt
          python scripts/generate_internal_links.py --incremental

      - name: Build
        run: hugo --minify --gc

      - name: Deploy to Cloudflare Pages
        uses: cloudflare/pages-action@v1
        with:
          apiToken: ${{ secrets.CLOUDFLARE_API_TOKEN }}
          accountId: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}
          projectName: github-help-wanted
          directory: public
```

**交付物**:
- [ ] `.github/workflows/scheduled-deploy.yml`
- [ ] `scripts/decide_deploy.py`
