## 1. 整体策略

### 双轨并行

| 轨道 | 目的 | 内容类型 | 占比 |
|------|------|----------|------|
| 轨道 A | 唤醒域名权重，承接外链 | Open Source、GitHub Pages | 20% |
| 轨道 B | 商业变现 | DevOps、SDLC、Unit Testing、Product Management | 80% |

### pSEO 包围策略

1. 先用 pSEO 批量产出长尾词页面（KD ≤ 25）
2. 形成词簇，建立主题权威
3. 最终攻占大词（Volume 10K+）

## 4. 外链承接

### `/open-source/` 分类详解

| 页面 | 承接URL | 原外链来源 |
|------|---------|-----------|
| `/open-source/` | Pillar | Qiita系列、HN |
| `/open-source/hacktoberfest/` | `?labels=hacktoberfest` | Scrapbox |
| `/open-source/good-first-issue/` | 核心语义 | Qiita、envader |
| `/open-source/python/` | `?languages=Python` | 筛选页外链 |
| `/open-source/javascript/` | `?languages=JavaScript` | 潜在 |
| `/open-source/beginners-guide/` | 新建 | 补充内容 |
| `/open-source/how-to-contribute/` | 新建 | Qiita上下文 |
| `/open-source/first-contribution/` | 新建 | 补充内容 |
| `/open-source/outreachy/` | 新建 | 补充内容 |

### 301 重定向规则

```nginx
# 旧筛选URL → 新静态页
rewrite ^/\?languages=Python.* /open-source/python/ permanent;
rewrite ^/\?languages=JavaScript.* /open-source/javascript/ permanent;
rewrite ^/\?labels=hacktoberfest.* /open-source/hacktoberfest/ permanent;
rewrite ^/\?labels=help[\+\%20]wanted.* /open-source/good-first-issue/ permanent;
rewrite ^/\?labels=good[\+\%20]first[\+\%20]issue.* /open-source/good-first-issue/ permanent;

# 其他带参数URL → 首页
rewrite ^/\?.* / permanent;
```

## 8. 内链策略

```
Pillar Page (大词)
    ↑↓ 双向内链
Cluster Pages (长尾词)
    ↑↓ 双向内链
扩展 Pages (子话题)
```

### 内链规则

- 每个 Cluster 页面：
  - 向上链接 Pillar（1个）
  - 平行链接相关 Cluster（2-3个）
  - 向下链接 扩展页（1-2个）

- 每个 Pillar 页面：
  - 链接所有直属 Cluster
  - 在正文中自然内链

- 跨 Category 内链：
  - 相关主题互链（如 DevOps ↔ SDLC）
  - 保持语义相关性
