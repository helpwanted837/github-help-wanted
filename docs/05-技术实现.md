## 首页承接方案

原站首页是一个 GitHub Issue 聚合工具，有大量外链指向。

**方案选择**:

| 方案 | 工作量 | 效果 | 推荐 |
|------|--------|------|------|
| A. 重建工具功能 | 高 | 完美承接 | 如果有时间 |
| B. 工具目录首页 | 中 | 良好承接 | 推荐 |
| C. 博客首页 | 低 | 勉强承接 | 不推荐 |

**推荐方案 B**:
- 首页展示工具分类卡片
- 保留 "Help developers find..." 的语义
- 添加搜索功能
- 引导到具体工具评测页

## 筛选页 URL 承接

原站有带参数的筛选页获得了外链：

```
/?languages=Python&labels=help+wanted...
/?labels=hacktoberfest...
```

**方案**: 创建静态页面 + 301 重定向（Pages Functions）

说明：

- Cloudflare Pages 的 `_redirects` 不支持“按 query 参数匹配 source”（官方限制）。
- 因此这里用 `functions/index.ts` 读取 query 并返回 301。

对应内容页：
- `/open-source/python/` - Python 开源项目贡献指南
- `/open-source/hacktoberfest/` - Hacktoberfest 参与指南
