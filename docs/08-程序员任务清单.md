**问题**：当前 CSS 颜色对比度不符合 WCAG AA 标准

**文件**：`assets/css/main.css`


### 2. 实现引用 Shortcode

**需求**：文案需要插入权威引用，需要统一样式

**文件**：`layouts/shortcodes/cite.html`

**用法**：
```markdown
{{</* cite
  url="https://survey.stackoverflow.co/2024/"
  author="Stack Overflow"
  title="2024 Developer Survey"
  year="2024"
*/>}}
```

**实现**：
```html
{{- $url := .Get "url" -}}
{{- $author := .Get "author" -}}
{{- $title := .Get "title" -}}
{{- $year := .Get "year" | default "" -}}

<cite class="cite-reference">
  <a href="{{ $url }}" target="_blank" rel="noopener noreferrer">
    {{- if $author }}{{ $author }}{{ if $year }} ({{ $year }}){{ end }}: {{ end -}}
    <em>{{ $title }}</em>
  </a>
</cite>
```

**CSS**：
```css
.cite-reference {
  font-size: 0.875rem;
  color: var(--muted);
}
.cite-reference a {
  color: var(--brand);
}
```

**验收标准**：
- [ ] Shortcode 正常渲染
- [ ] 链接可点击且新窗口打开
- [ ] 样式与整体设计协调

## 🟡 P2 - 优化项（本周）

### 8. HowTo Schema 支持

**需求**：教程类文章需要 HowTo Schema

**文件**：`layouts/partials/schema/howto.html`（新建）

**Front Matter 格式**：
```yaml
howto:
  name: "How to Set Up GitHub Pages"
  totalTime: "PT30M"
  steps:
    - name: "Create a repository"
      text: "Create a new GitHub repository..."
    - name: "Enable GitHub Pages"
      text: "Go to Settings > Pages..."
```

**实现**：
```html
{{- $howto := .Params.howto -}}
{{- if $howto -}}
{{- $steps := slice -}}
{{- range $i, $step := $howto.steps -}}
  {{- $steps = $steps | append (dict
    "@type" "HowToStep"
    "position" (add $i 1)
    "name" $step.name
    "text" $step.text
  ) -}}
{{- end -}}

{{- $data := dict
  "@context" "https://schema.org"
  "@type" "HowTo"
  "name" $howto.name
  "totalTime" $howto.totalTime
  "step" $steps
-}}
<script type="application/ld+json">{{ $data | jsonify }}</script>
{{- end -}}
```

**验收标准**：
- [ ] HowTo Schema 正确生成
- [ ] Google Rich Results Test 通过

### 10. 代码块增强

**需求**：代码块需要复制按钮和语法高亮

**文件**：`layouts/partials/scripts.html`

**实现**：
```html
<script>
document.querySelectorAll('pre code').forEach(block => {
  const btn = document.createElement('button');
  btn.className = 'copy-btn';
  btn.textContent = 'Copy';
  btn.addEventListener('click', () => {
    navigator.clipboard.writeText(block.textContent);
    btn.textContent = 'Copied!';
    setTimeout(() => btn.textContent = 'Copy', 2000);
  });
  block.parentElement.style.position = 'relative';
  block.parentElement.appendChild(btn);
});
</script>
```

**CSS**：
```css
.copy-btn {
  position: absolute;
  top: 0.5rem;
  right: 0.5rem;
  padding: 0.25rem 0.5rem;
  font-size: 0.75rem;
  background: rgba(255, 255, 255, 0.1);
  border: 1px solid var(--border);
  border-radius: 6px;
  color: var(--muted);
  cursor: pointer;
}

.copy-btn:hover {
  background: rgba(255, 255, 255, 0.15);
  color: var(--text);
}
```

**验收标准**：
- [ ] 代码块有复制按钮
- [ ] 点击后显示 "Copied!" 反馈
