## 文章类型分布

| 类型 | 数量 | 占比 | 示例 |
|------|------|------|------|
| 对比评测 (vs) | - | - | "Tool A vs Tool B" |

## URL 结构规划

```
/                           # 首页（必须承接外链）
/tools/                     # 工具索引
/tools/[tool-name]/         # 单工具评测
/compare/                   # 对比索引
/compare/[a-vs-b]/          # 对比页面
/guides/                    # 指南索引
/guides/[topic]/            # 指南页面
/blog/                      # 博客/资讯
```

## 必须承接的 URL（来自 01-域名分析）

| 原 URL | 承接方案 | 新 URL |
|--------|----------|--------|
| `/` | 保留 | `/` |
| `/?languages=Python&labels=help+wanted...` | 301 或静态页 | `/python/` 或 `/guides/python-open-source/` |
| `/?labels=hacktoberfest...` | 301 或静态页 | `/hacktoberfest/` |

## 发布节奏

| 阶段 | 时间 | 数量 | 说明 |
|------|------|------|------|
| Phase 1 | Month 1-2 | 50 篇 | 核心页面 + 高优先级关键词 |
| Phase 2 | Month 3-4 | 100 篇 | 扩展覆盖 |
| Phase 3 | Month 5-6 | 100 篇 | 长尾词 + 补充内容 |
| Phase 4 | Month 7+ | 50 篇 | 持续更新 + 时效性内容 |

### 每日发布计划

- 每天 2 篇
- 上午 1 篇（08:00-12:00 随机）
- 下午 1 篇（14:00-18:00 随机）
