## 每篇必须包含

1. **Key Takeaways** - 文章开头的要点提炼（3-4条）
2. **References** - 文末 5+ 条权威来源引用
3. **FAQ** - Front Matter 中定义 + 正文中展开
4. **表格** - 工具对比、功能对比、或方法对比
5. **引用块** - 专家观点或权威数据

## Front Matter 必填

```yaml
---
title: "标题（60字符内）"
description: "描述（150-160字符）"
date: 2025-XX-XXT10:00:00+08:00
draft: true
type: cluster  # pillar/cluster/extension
pillar: "/parent/"  # 仅 cluster/extension
keywords: ["关键词1", "关键词2"]
faq:
  - question: "问题?"
    answer: "答案..."
---
```
